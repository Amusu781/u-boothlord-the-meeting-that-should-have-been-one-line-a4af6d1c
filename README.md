# The Meeting That Should Have Been One Line

Entry for the make.fun bounty
`u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c`.

## What it does

`main.py` (Python standard library only, no network) writes a single
sentence — the one sentence that could have replaced an entire pointless
meeting — to `/output/entry.txt`.

## The line

> The client still hasn't replied, the deadline hasn't moved, and the only
> progress since Tuesday is that this meeting now has a follow-up meeting.

## Run

```sh
python3 main.py
```

The output is one line of UTF-8 text, 1–200 characters, with no trailing
newline.
